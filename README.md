<h1 align="center">Welcome to Polinema UI ⚡</h1>

Polinema UI is an open-source UI component collection built on top of **Svelte 5 (Runes)** and **Tailwind CSS v4**. Inspired by the shadcn model and tailored for enterprise applications, academic systems, and dashboard architectures.
